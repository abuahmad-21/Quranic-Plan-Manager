الموضوع: بناء نظام "ترتيل" مفتوح المصدر باستخدام تقنيات Edge AI و Open Source
أريدك أن تعمل كـ Lead Software Architect. أريد بناء تطبيق ويب (Next.js) يحاكي تجربة تطبيق "ترتيل" بالاعتماد كلياً على أدوات مجانية ومكتبات مفتوحة المصدر. إليك التفاصيل التقنية لكل ميزة، وأطلب منك كتابة الكود والمنطق البرمجي لها:
1. معالجة الصوت والتعرف على الكلام (Speech-to-Text):
• الأداة: استخدم نموذج OpenAI Whisper (نسخة tiny أو base) التي يمكن تشغيلها داخل المتصفح مباشرة باستخدام Transformers.js ليكون التعرف فورياً ومجانياً (Client-side).
• المطلوب: كود يربط الميكروفون بـ Web Worker لتحويل صوت التلاوة إلى نص لحظي دون الحاجة لسيرفر مدفوع.
2. الربط بين الكلمة والنص (Word-by-Word Mapping):
• الأداة: استخدم خوارزمية Levenshtein Distance أو Dynamic Time Warping (DTW) لمقارنة النص الخارج من Whisper مع نص القرآن الكريم.
• قاعدة البيانات: استخدم قاعدة بيانات Quran.com API أو ملفات JSON للقرآن (مفتوحة المصدر) المتوفرة على GitHub.
• المطلوب: منطق برمجى (Logic) يقوم بتظليل الكلمة الحالية في المصحف بناءً على توقيت نطقها.
3. التصحيح التلقائي وتنبيه الأخطاء (AI Error Detection):
• الآلية: إذا كانت نسبة التطابق بين الكلمة المنطوقة والكلمة الأصلية أقل من 80%، قم بتغيير لون الكلمة في الواجهة إلى اللون الأحمر مع تفعيل خاصية الاهتزاز (Haptic Feedback).
• المطلوب: وظيفة (Function) تقارن "الفونيمات" (Phonemes) العربية لتمييز الأخطاء في الحركات الإعرابية.
4. وضع التسميع (Memorization Mode):
• التنفيذ: واجهة مستخدم (UI) بـ Tailwind CSS تجعل الآيات غير مرئية (Opacity-0). عند تطابق الصوت مع الكلمة، تظهر الكلمة بتأثير (Fade-in).
• المطلوب: كود الحالة (State Management) باستخدام Zustand أو React Hooks للتحكم في ظهور الكلمات.
5. البحث الصوتي والذكاء المحيط:
• الأداة: استخدام Vector Embeddings بسيطة (مثل Supabase Vector أو Pinecone النسخة المجانية) لتخزين متجهات الآيات والبحث عنها صوتياً.
6. المصادر المجانية المطلوبة:
• استخدم مكتبة React-Use-Gesture للتعامل مع اللمس.
• استخدم Lucide-react للأيقونات.
• استخدم Shadcn/ui لبناء المكونات.
المطلوب منك الآن:
1. رسم هيكلية الملفات (Folder Structure).
2. كتابة كود صفحة "المصنف الذكي" التي تستمع وتصحح فوراً.
3. شرح كيفية تشغيل نموذج Whisper داخل المتصفح (Browser) لتوفير تكاليف الـ API.
