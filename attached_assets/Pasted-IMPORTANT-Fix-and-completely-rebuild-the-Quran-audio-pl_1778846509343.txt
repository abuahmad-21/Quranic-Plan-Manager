=== BUG 1: LAST WORDS CUT OFF ===
The current audio cuts off the last words of ayahs.
ROOT CAUSE: everyayah.com MP3 files have silence trimmed 
too aggressively.

FIX: Switch to Quran.com CDN audio which has proper endings:
https://verses.quran.com/{reciterSlug}/{surah3}{ayah3}.mp3

Example for Alafasy, Surah 1, Ayah 1:
https://verses.quran.com/Alafasy/mp3/001001.mp3

Also add 300ms silence at end before playing next ayah:
audioElement.onended = () => {
  setTimeout(() => playNextAyah(), 300)
}

=== BUG 2: GAPS BETWEEN AYAHS ===
There is silence/gap between ayahs during continuous play.

FIX: Use Audio preloading - while ayah N plays, preload N+1:
const preloadAudio = new Audio()
preloadAudio.src = getAudioUrl(nextSurah, nextAyah, reciter)
preloadAudio.preload = 'auto'

=== BUG 3: AUDIO FAILS SILENTLY ===
If audio URL fails, nothing happens. User doesn't know.

FIX: Add fallback chain:
1. Try verses.quran.com first
2. If fails → try everyayah.com as backup  
3. If both fail → show error toast in Arabic: 
   "تعذّر تحميل الصوت، تحقق من الاتصال"
