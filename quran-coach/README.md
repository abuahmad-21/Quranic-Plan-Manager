# Quantum Quran Coach v2

تطبيق حفظ القرآن الكريم بنظام كوانتمي تكيُّفي. يعمل بدون أي اعتماديات خارجية على Termux/Android.

## التشغيل على Termux

```bash
pkg install nodejs
cd quran-coach
node server.js
```

ثم افتح المتصفح على `http://localhost:3000`

## بنية الملفات

```
quran-coach/
├── server.js           # سيرفر HTTP خالص (بدون اعتماديات)
├── ai_core.js          # محرّك الذكاء (Kalman, ML, تكييف الخطة...)
├── db.json             # قاعدة البيانات (JSON)
├── package.json
├── data/
│   ├── alerts.json     # تنبيهات سياقية
│   ├── surahs.json     # السور
│   └── techniques.json # تقنيات الحفظ
├── public/
│   ├── index.html      # SPA
│   ├── style.css       # تصميم زجاجي داكن
│   └── app.js          # واجهة المستخدم + المستشعرات + IndexedDB
└── uploads/            # (محجوز — لا يُستخدم حالياً، البيانات الثقيلة على جهاز المستخدم)
```

## الميزات

### المستخدم
- تسجيل دخول/إنشاء حساب
- تهيئة خطة حفظ تكيُّفية
- جلسة حفظ مع تتبّع نفسي (Kalman + ML)
- خطة 30 يوم تتعدّل ذاتياً حسب التسويف/الغياب/الجودة
- مكتبة شخصية صوتية وصورية **محفوظة كاملة على جهاز المستخدم (IndexedDB)** — السيرفر لا يستقبل أي بيانات ثقيلة
- منشورات نص + مصغّر صورة فقط (الصورة الأصلية على الجهاز)
- تسجيل صوتي للجلسات (في المكتبة)
- إرسال رسائل صوتية بين الأصدقاء بشرط الإذن المسبق
- صداقات + بحث + طلبات
- محادثات فردية + مجموعات
- تذاكر دعم فني (شات مع الإدارة)
- لوحة المتصدرين

### الإدارة (`admin123` افتراضياً، غيّرها في `db.json` بعد أول تشغيل)
- نظرة عامة + إحصاءات
- إدارة المستخدمين (حظر/إلغاء حظر/حذف)
- حذف أي منشور
- مراقبة كل المحادثات وحذف رسائل
- إدارة تذاكر الدعم والرد عليها
- إعلانات عامة (Broadcast)
- ضبط أوزان الخوارزميات حياً

## الخصوصية وتوفير مساحة السيرفر

كل البيانات الثقيلة (تسجيلات صوتية، صور كاملة) **تُحفظ في IndexedDB على جهاز المستخدم فقط**. السيرفر يخزّن فقط:
- بيانات الحساب والتقدّم
- نصوص المنشورات + مصغّر صورة (240px JPEG ضغط 70%)
- نصوص الرسائل + مرجع وقتي للرسائل الصوتية (الصوت نفسه عند المُرسِل)
- إعدادات الإدارة

## الخوارزميات

- **Kalman Filter** لدمج إشارات المستشعرات
- **EWMA / Holt-Winters** للتنبؤ بالطاقة
- **SGD محلي** لتعلم وزن الإشارات
- **SR (SM-2)** للمراجعة المتباعدة
- **PlanAdapter** لإعادة حساب الهدف اليومي بناءً على: الجودة، الغياب، التسويف، اتجاه الطاقة
- **Procrastination Detector** لكشف التسويف
- **Circadian Multiplier** لتعديل الطاقة حسب الساعة

## تغيير كلمة مرور الإدارة

افتح `db.json` وعدّل `admin.password_hash` (SHA-256 hex). لتوليد قيمة:

```bash
node -e "console.log(require('crypto').createHash('sha256').update('YOUR_PASSWORD').digest('hex'))"
```
